# Prompts for the animal design drawings

Paste one prompt per animal into Gemini (image generation). Every prompt
repeats the same style block, so the six come out looking like one family.
Generate a few, pick the cutest, and save it here as `<animal>.png`
(e.g. `cat.png`). Several poses of one character in one image is what the
3D modelling needs: the views set the proportions.

Tips:
- The panda gets a third pose, sitting upright with bamboo, because in the
  app it sits up whenever it stops walking.
- Extra legs (e.g. a six-legged panda) usually mean two poses got merged.
  Ask Gemini: "Redraw this exactly, but give the character exactly four
  legs in each pose (two front, two back), and leave clear empty space
  between the poses so they don't overlap."
- If the views don't match (different ear shapes, colours), ask Gemini:
  "Keep the exact same character, but make the other views match the
  front view."
- No scarf or clothes: the app adds a scarf in each player's chosen colour.
- If one comes out great, attach it when generating the others and add
  "in the same style as this image".
