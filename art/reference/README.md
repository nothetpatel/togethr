# Animal design drawings

Drop your 2D designs here, one or more per animal:

- `dog-front.png`, `dog-side.png`
- `cat-front.png`, `cat-side.png`
- `panda-…`, `koala-…`, `turtle-…`

Front and side views work best (they set the proportions); a single drawing
is fine too. PNG or JPG, any size. Colours in the drawing become the model's
colours.

The Blender build scripts live in `scripts/blender/`; preview renders go to
`art/previews/<animal>/`.
